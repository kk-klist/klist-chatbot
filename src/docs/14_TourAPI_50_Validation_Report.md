## 실행 방법

Docker가 실행 중인 환경에서 다음 환경변수를 주입한 뒤 테스트를 실행한다.

```powershell
$env:TOUR_API_SERVICE_KEY='<발급받은 키>'
$env:TESTCONTAINERS_RYUK_DISABLED='true'
.\gradlew.bat liveTourApiTest --tests "com.klist.chatbot.tourapi.TourApiLivePostgreSqlIntegrationTest"
```

로컬 Docker의 Ryuk 포트 바인딩이 정상인 환경에서는
`TESTCONTAINERS_RYUK_DISABLED`를 생략할 수 있다.

## 발견 사항과 검색 영향

기존 `detailCommon2` 요청에 포함된 구형 `defaultYN`, `overviewYN` 등의 옵션은
현재 `KorService2` 응답에서 설명과 홈페이지 필드를 비우는 원인이었다. 해당 옵션을 제거한 뒤
설명 누락이 50건에서 0건으로, 공식 URL 누락이 50건에서 30건으로 개선됐다.

지역 코드 누락 29건은 원본 `areaBasedList2`의 `areacode` 누락이다. 법정동 지역 코드는 별도
필드에 존재하지만 코드 체계가 다르므로 임의 변환하지 않았다. 이 데이터는 키워드·좌표 검색에는
사용할 수 있지만 `areaCode` 필터에서 제외될 수 있다. 공식 URL이 없는 30건은 관광지 추천과
설명 검색에는 사용할 수 있으나 공식 링크 근거를 제공할 수 없다.

## 후속 범위

- 100건·500건·전체 수집에서 누락률 추세를 다시 측정한다.
- 지역 필터 커버리지가 필요하면 법정동 코드와 TourAPI 지역 코드 사이의 공식 매핑 정책을 별도로 설계한다.
- 공식 URL이 없는 결과는 응답 생성 시 URL을 추정하지 않고 미제공으로 유지한다.
